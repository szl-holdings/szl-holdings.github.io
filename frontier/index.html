Evidence boundary

This is a dated, public-only metadata atlas. Hugging Face was collected anonymously, so private inventory is outside this view. Filenames and card declarations are observations; no model was loaded, trained or independently evaluated, and no repository code, formal proof, signature, deployment or runtime was rechecked. The software collection is an editorial selection from the public GitHub census; archived aliases are excluded as distinct capabilities. Its count is not a theorem count or a claim that every public repository is mathematical software.
